# Museum Management System

This project implements a museum management system using Object-Oriented Programming in Python.  
It models art displays, subscribers, and their interactions within a museum.

## Overview
The system allows managing art displays (paintings and statues), handling subscribers, tracking their entries, and analyzing the most popular displays.

## Features
- Create and manage art displays
- Represent paintings and statues as objects
- Manage museum subscribers
- Track remaining subscriber entries
- Load museum data from a text file
- Identify the most popular art displays among subscribers

## Technologies
- Python
- Object-Oriented Programming (OOP)
- File Handling

## Main Classes
- ArtDisplay – represents an art display in the museum
- MuseumSubscriber – represents a subscriber with entry tracking
- Museum – manages displays and subscribers

## How to Run
Example file: museum.txt
1. Create a text file named museum.txt with the required format  
2. Run the program:
   python museum_management.py

## Example Output
- List of art displays in the museum  
- Subscriber entry updates  
- Most popular art displays
